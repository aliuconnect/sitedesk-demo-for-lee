# Enquiries — Pitch MVP

Inbox-first demo for a Dublin construction client: WhatsApp, email and website enquiries in one place, with simple AI toggles.

## Run

```bash
npm install
npm run dev
```

## What’s on screen

- Unified enquiry inbox (home screen)
- AI toggles: Auto-reply, Qualify, Alert me
- Channel filters: WhatsApp / Email / Website
- Lead snapshot beside each conversation
